# Sort out a messy folder

*A free mini course from Liminal CX (liminalcx.com/free). Paste all of this into the AI chat you use (Claude, ChatGPT, Copilot or Gemini), then reply to its first question.*

---

## Instructions for the AI

You are helping me (a PA, admin or busy founder) tidy up one messy folder on my computer. We practise on a test folder of copies first. Then you save how we did it as a reusable set of instructions, so next time I only have to say "organise this folder".

How to work with me:

1. **One step at a time.** Follow the steps below in order. Explain the step in two or three lines, wait for me to do it or say "done", then move on.
2. **Check what you can do first.** Before anything else, tell me in two or three lines whether you can, on my plan:
   - (a) open a folder on my computer and see what's in it
   - (b) create folders and move files
   - (c) save a reusable set of instructions (some tools call this a skill, a custom GPT, an agent or custom instructions)

   If you can browse the web, check your own official help page (links below) for the current answer. Features and plans change often. If you can't work with files on my computer, say so honestly and follow "If you can't touch my files" instead.
3. **Plan first, always.** Never move, rename or delete anything until you've shown me the plan and I've said yes.
4. **Never delete or rename.** Only create folders and move files. Exact duplicates go into a `_Duplicates` folder with a short note saying what each one copies. I decide later whether to delete them.
5. **Plain English, no jargon.** I'm not technical. Keep it short and friendly.

## Questions to ask first, one at a time

1. **Which folder bugs you most?** Downloads, old photos, receipts, a project folder? *Suggest: something with 10 to 20 files you know well, so you can spot a mistake.*
2. **When you look for something in there, what do you think of first?** A person, a client, a year, a type of document? *Suggest: if you're not sure, start by file type (photos, documents, spreadsheets) and change it later.*
3. **Is it a work folder?** If so, check your company is happy for an AI tool to see those files before we connect anything.

## Steps

### Step 1: Make a test folder

- Ask me to make a new folder called **Test Folder** somewhere easy to find, such as Documents.
- Ask me to **copy** (not move) 10 to 20 files from the messy folder into it. On Windows, hold Ctrl while dragging. On a Mac, hold Option.
- Tell me: these are copies, so nothing can go wrong with my real files.

### Step 2: Connect the folder

- Walk me through connecting the Test Folder to you, using your own settings. Check your official help page for where this is now. *(At the time of writing in Claude: open the desktop app, choose Cowork at the top, then choose the folder under the message box.)*
- Remind me to connect the **folder**, not attach the files one by one. Attached files are copies you can read but not move.

### Step 3: Look, then show me a plan

- Tell me what's in the folder: how many files, what types, anything that looks like a duplicate or has an unhelpful name.
- Propose a folder layout using my answer to question 2. Show it as a simple tree.
- Say clearly: **"Nothing has moved yet."**
- Ask me: "When you look for something here, is this how you'd look?" Offer one alternative (for example by person instead of by file type).
- Change the plan until I'm happy. Expect at least one round of changes.

### Step 4: Do it

- Only once I say yes: create the folders and move the files.
- Put anything you can't place in an **Unsorted** folder.
- Put exact duplicates in `_Duplicates` with a note. List near-duplicates (for example two scans of the same photo) for me to check, and leave them where they are.
- Write a short **README** file in the folder: what's in each folder, what you set aside, and what still needs me.
- Tell me how many files you moved.

### Step 5: Check it together

Ask me to open the folder myself and check:
- Do the folders make sense to me?
- Open two or three at random: is everything in the right place?
- Is anything missing? Count the files if you can.
- Point out anything you weren't sure about.

### Step 6: Save it as a recipe

- Save how we did this as a reusable set of instructions called **folder organiser**, using your own feature for that (check your help page).
- Include my rules: look first, show a plan and wait for my yes, sort by [my answer], never delete or rename, set duplicates aside with a note, leave a README.
- Tell me where it's saved and how to change it.

### Step 7: Test the recipe

- Ask me to make a second small test folder and, in a new chat, connect it and say only **"Organise this folder."**
- It should show me a plan and wait. If it doesn't, help me fix the recipe.
- Then suggest I try it on the real folder.

## If you can't touch my files

- Ask me to paste in a list of the file names. *(Windows: select the files, hold Shift, right-click, Copy as path. Mac: select the files, Copy, then paste into the chat.)*
- Write the plan as a tree, then a checklist: "Make these folders, then move these files into each one."
- Write the README text for me to save in the folder.
- Write the recipe as a short block of instructions I can save and paste in next time.

---

## When we're finished

Give me:

1. The final folder layout, as a tree.
2. What was set aside as duplicates, and what still needs me.
3. Where the folder organiser recipe is saved, and the one sentence that runs it.
4. The official help link for the tool we used.
