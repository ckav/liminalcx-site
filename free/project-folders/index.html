Why a README?

Your AI reads one page, not every file

A README is a short text file at the top of a folder. It says what the folder is for, what's in it, which files are the latest and what happens next. It's saved as README.md, plain text that any AI tool can read in an instant.

For your AI

It reads one page instead of opening every file, so it's quicker and gets it right more often. A brand-new chat can pick up exactly where the last one left off.

For you

The latest version of everything, key decisions and next steps, all at a glance. No more "budget FINAL v3 (2).xlsx".

For anyone covering for you

A colleague or stand-in can find their way around the project without having to ask.

Where everything goes

Projects, Areas, Resources, Archive

The four top-level folders come from Tiago Forte's PARA method in Building a Second Brain. Every file in your working life fits one of them.

1

Projects

Things you’re actively working on, with a goal and a deadline.

A product launch, the summer away day

2

Areas

Your roles and responsibilities: a standard to keep up, with no end date.

Finance, team, suppliers

3

Resources

Things you’re interested in or might use.

Slide templates, brand guidelines, how-to guides

4

Archive

Completed or inactive things.

Finished projects and old versions

Archiving is what keeps this working: old versions and finished projects move out of the way, so the latest document is always the one your AI finds first.

Where does a file go?

Ask three questions, in order

  1. Will it help move a current project forward?Projects
  2. Will it help you keep up an ongoing responsibility?Areas
  3. Will it support one of your interests?Resources
  4. None of these? Is it really worth keeping?Probably not

Your AI asks the same questions every time it files something. When it isn't sure, it never deletes: it adds the file to "Needs you" in the README.

Rules the course follows

  • Never create an empty folder. Folders appear only when there's a file to go in them.
  • Move quickly, touch lightly. There's no one perfect place. Pick a good one and move on.
  • Search is your friend. Search first, then look in folders.
  • When in doubt, start over. Archive everything with today's date and start fresh.

The questions and rules come from Tiago Forte's PARA cheat sheet, and they're built into the instructions you copy below. Read his free introduction to PARA.
